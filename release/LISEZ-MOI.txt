Net-Companion Lite — binaire portable
=====================================

Diagnostic reseau de terrain, sans installation ni droits administrateur.
Tout tourne en local sur la machine ; aucune donnee ne quitte le poste.

UTILISATION
-----------
1. Copiez le .exe sur votre cle USB (ou lancez-le directement).
2. Double-cliquez le .exe.
   (Windows SmartScreen peut prevenir au 1er lancement, le binaire n'etant pas
    signe : « Informations complementaires » -> « Executer quand meme ».
    Un antivirus peut aussi alerter : un outil qui scanne le reseau, c'est normal.)
3. Le navigateur s'ouvre sur http://127.0.0.1:8080
4. Creez un code PIN, puis cliquez « Mode demo » pour tout essayer sans materiel.
   (Le PIN chiffre vos identifiants SNMP/SSH en local, en AES-256.)

Pour arreter : fermez la fenetre console.

CE QUE FAIT L'OUTIL
-------------------
- Radar & inventaire : decouverte + identification typee des appareils
  (pare-feu, switch, serveur, imprimante, NAS, VoIP, camera, PC...),
  vue arborescente + carte topologique, export PNG/CSV.
- Diagnostic de connectivite complet (13 points) : interface/MTU, serveurs DNS,
  passerelle + latence, DNS, acces + latence Internet, perte de paquets, ports
  sortants, IPv6, portail captif, IP publique, debit ; + diagnostic par appareil.
- Score de sante /100 + detection d'anomalies.
- Check de site (1 clic) + rapport professionnel exportable (HTML / JSON).
- Avec identifiants SNMP/SSH (coffre) : Port-Finder (switch/port/VLAN),
  voisinage LLDP/CDP, Config-Diff & derive.
